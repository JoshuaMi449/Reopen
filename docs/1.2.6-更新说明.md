# Reopen 1.2.6 更新内容

历史图弹窗的位置改为对齐它对应的那张卡片。

## 改动

- **点哪张卡片，弹窗顶部就对齐哪张卡片**。此前弹窗一律定位在面板顶部往下 10px，点下面的「电池」「网络」时，弹窗和它对应的卡片离得很远，看不出两者是一对。

  现在展开时会读取被点卡片在面板里的顶部坐标，传给弹窗作为定位锚点；超出屏幕可用区域时仍会向内收，不会被挤出屏幕。

- 设置里拖色板时的颜色预览没有具体卡片可对齐，仍沿用面板顶部，行为不变。

## 验证

- `npm test`：诊断引擎黄金文本 + 原有 10 项回归全部通过。
- `npm run typecheck`。
- 用调试协议实测：点击卡片后读取弹窗窗口的实际屏幕纵坐标，与「面板纵坐标 + 卡片在面板内的顶部坐标」比对。
