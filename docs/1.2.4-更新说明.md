# Reopen 1.2.4 更新内容

继续改历史图的跟手度。（后续实测证明：本版和 1.2.3 一样没有命中真正的原因，真正的原因见 1.2.5。）

## 修复

- **历史图十字线跟手度（真因）**：1.2.3 改的是 `getBoundingClientRect()`，但它在进入某张图时只量一次，一次滑动里根本不调用——**它不是瓶颈**。

  真因是：每跨过一列 → 更新十字线位置 → **整张图连同 480 个柱子元素（CPU 120×3、内存 120×4）一起重建**。快速左右滑一秒能跨过上百列，等于每秒重建十几万个 React 元素，掉帧就是这么来的。

  柱子只取决于数据、跟十字线在哪一列毫无关系，却每次都跟着重建。现在把四种大图（CPU / 内存 / 网络 / 电池）的柱子各自拆成独立组件并 `memo`：滑动时柱子整块跳过，每次跨列只剩下**十字线的那一条线**和提示框要更新。

## 说明

- 绘制方式**仍是 SVG**，没有改成原生绘制。原因见下。
- 面板窗口是「透明 + 毛玻璃（vibrancy）」的，系统每次重绘都要把网页重新和背后的模糊底混合一遍——这是和 iStat Menus 手感差距的另一半来源，且属于外观设定，不是能简单绕开的东西。
