# Reopen 1.2.3 更新内容

改善历史图窗口里鼠标左右滑动的跟手度。

## 优化

- **历史图十字线跟手度**：此前鼠标在 CPU / 内存 / 网络 / 电池历史图上左右移动时会有顿感。原因是每次 `mousemove` 都调用了 `getBoundingClientRect()`——它会强制浏览器同步重算布局；紧接着的 `setState` 又改动 DOM，形成「读布局 → 改 DOM → 再读布局」的高频交替，鼠标一秒动几十次就是几十次强制重排。

  现在：进入某张图时量一次尺寸并缓存（历史图窗口固定尺寸不可缩放），且只在**跨列**时才更新高亮索引——同一列内移动不再触发任何重算。

## 说明

本次只优化了渲染路径，**没有改动绘制方式**（仍是 SVG）。如果实际体验下来仍觉得不够跟手，再考虑把历史图搬到原生绘制（项目已有原生模块基础）。
