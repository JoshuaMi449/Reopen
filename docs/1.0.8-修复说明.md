# Reopen 1.0.8

- CPU 卡片改为真实使用率历史面积图：每 2 秒采样，展示最近 1 分钟，使用系统主题色填充折线下方区域。
- 删除权限预热后失焦 4 秒强制抢回前台的逻辑；窗口加载完成前不提前显示。
- 服务/网页分类与启动按钮统一按项目能力判断。包含开发服务器等服务方式的项目归服务，即使当前选择成品预览；解散组后同样适用。
- 只有纯网页自动常驻；其他项目需要明确加入自启项。后台自动启动不打开浏览器，原有组自启规则保持。
- 日志在主进程按项目保存最近 2000 行，界面加载/重建时补读，序号用于去重并衔接实时日志。
- 日志来自启动命令的 stdout、stderr，以及 Reopen 生成的启动、端口、网关诊断。stdout/stderr 分别缓冲，进程结束时补齐末尾无换行文本。
- 外部已运行进程只同步运行状态，不代表 Reopen 自动启动；无法取回外部进程之前的 stdout/stderr，会明确提示。使用重启可由 Reopen 启动并记录新的输出。
- 复制日志按钮移入日志框右上角；停止、重启、在浏览器打开、编辑、删除保持单行。重启操作等待停止后重新启动。
- package.json、锁文件根版本和界面版本统一为 1.0.8。

## 验证

- `npm test`：真实 npm 子进程验证界面未加载时的启动标题、stdout/stderr、无换行尾行；另验证分类、自动启动范围、后台不开浏览器、日志序号及重启。
- `npm run build`：TypeScript 检查与 Electron/React 构建通过。
- `npm run lint`：无错误；保留未涉及文件原有的 3 个格式警告。
- Electron 实际渲染：456 像素抽屉内五个按钮在同一行，复制按钮位于日志框内右上角，无横向内容溢出。

日志仅保留本次 Reopen 进程运行期间的最近 2000 行，不伪造外部服务或旧版本已丢失的启动日志。

## 追加界面修正

- CPU 历史图改为蓝色用户、粉色系统的堆叠柱图，绘图区从 18px 增到 40px，保持真实 0–100% 比例；未采样区显示完整基线。
- 网络速度右侧增加紫色上传、粉色下载的上下柱图，各自按历史峰值缩放；鼠标提示说明峰值和缩放口径。
- 日志隐藏滚动条，仍可滚轮滚动和选中文字。
- 普通单击替换选中并打开对应日志；⌘ 单击切换多选，Shift 单击范围选中，空白/Esc 清空。分类、搜索切换和关闭日志清理选择；窗口失焦结束框选。

## CPU / 电池并排图表

- 菜单面板改为 420×480，CPU 历史图移到详情文字右侧；右侧五个按钮使用等分网格，与左卡片底边对齐。
- 电池右侧新增 iStat 风格的电量历史：接电蓝柱、使用电池粉柱，底部接电区间条，实际充电区间附闪电标记。
- 电源身份根据适配器连接状态判断，避免把充电上限/充电暂停误报为电池供电。
- 每分钟保存真实电池历史，面板关闭后继续采样；保留两小时，写入用户数据目录 battery-history.json。未记录的区间留空。
- Electron 渲染验证左右底边相差小于 1px，全卡片内容在面板内。
