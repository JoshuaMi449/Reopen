# Reopen 1.2.2 更新内容

修一个隐藏较深的显示问题。

## 修复

- **深色模式下「储存·可用」的自定义颜色不生效**：托盘面板里储存进度条那截「可用」的空槽，深色模式下一直显示系统默认的半透明白，而不是你设置的颜色（浅色模式正常，所以很容易漏掉）。

  原因：深色模式有一条 `:root.dark .sys-bar` 的底色规则，CSS 特异性比 `.tray-panel .sys-bar`（那条读自定义颜色的规则）高一级，把自定义颜色整个盖掉了。已让自定义规则在深色下保持同等特异性。

## 验证

- `npm test`：诊断引擎黄金文本 + 原有 8 项回归。
- `npm run typecheck`：静态检查。
- 用真实 CSS 在深色模式下渲染验证：进度条底色正确取到自定义颜色。
