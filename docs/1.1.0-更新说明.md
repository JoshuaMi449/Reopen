# Reopen 1.1.0 更新内容

相对 GitHub 上的 v1.0.7，本版集中改进菜单栏系统信息、配色和项目操作，并包含本地 1.0.8 阶段的修复。

## 菜单栏与配色

- 菜单栏面板及 CPU、内存、网络、电池历史弹窗跟随 **macOS 系统**浅色或深色外观，不受项目主界面主题影响。文字使用系统主题前景色，信息卡与图表区域采用实心底色，避免背景透出后降低可读性。
- 菜单栏图形颜色可按 CPU、内存、储存、电池、网络分别设置。新增 12 色分段色环、透明度与明度弧线、屏幕吸色器，以及 7 格待用颜色和 7 格已确认颜色。取色可拖动预览；色环显示经过当前系统主题对比度约束后的颜色，点击外侧确认。
- 打开色板时同步显示菜单栏面板和相应历史图，调整图形颜色实时预览；储存配色只打开菜单栏主面板。CPU 空闲、内存可用和储存可用允许 0% 透明度，其余图形颜色会限制到在当前内层底色上可辨识的范围。
- CPU 温度作为独立菜单栏项显示，每秒更新，不替换角色动图，也不改变动图的颜色或点击行为。

## 历史图与交互

- CPU、内存、网络、电池历史使用独立浮窗；图例和曲线/柱形颜色与菜单栏设置保持一致。电池的 1 天范围采用每格 15 分钟的 96 格时间轴，未采样的时间留空。
- 修复项目卡片右键同时打开日志导致主窗口变窄的问题；右键只显示项目管理操作，左键仍可查看日志。
- 项目服务的启动命令和 stdout/stderr 记录在主进程，窗口重新加载可衔接当前进程内的日志；外部已运行服务不会伪造历史输出。改进服务分类、自启行为和停止后重启的时序。
- 修复无权读取项目文件时的主进程异常处理，避免菜单栏被错误弹窗阻断；保留原有项目清单和设置数据。

## 验证

- `npm test`：项目启动/日志、右键菜单、菜单栏颜色与外观回归检查。
- `npm run build`：主进程、预加载脚本与渲染界面 TypeScript 检查及生产构建。
- `npm run lint`：静态检查。

仅提供 Apple Silicon macOS 安装包；使用本地签名，未进行 Apple Developer 公证。
