# Reopen 1.3.0 更新内容

主界面重做，项目可以置顶，首次打开的新手引导也重新设计了。

## 改动

- **主界面重做**：左侧分类栏 + 大标题 + 筛选药丸；组显示成文件夹卡，项目显示成「网页截图 + 信息板」卡片。运行中的网页会自动抓一张静态图铺在卡片顶部，没有截图时用组色渐变占位。
- **置顶**：卡片右上角图钉或右键菜单置顶。置顶项目固定在主界面最上方的「置顶」区，并按置顶先后排列，可以拖动调整顺序；菜单位置在面板项目列表最上方单独一组，不再在「网页/服务」里重复出现。
- **菜单栏面板跟随**：每次弹出都会重新读取项目与置顶清单，主窗口里改了置顶或项目名，面板下一次弹出就是最新的。
- **去掉列表视图**：只保留卡片视图，应用菜单里的「列表/卡片视图」一并移除。
- **新手引导重做**：欢迎页换成新的介绍与能力标签；六步引导依次是分类/组/标签、启停与日志、局域网分享、置顶、自启项、拖入添加；去掉了高亮外的描边框，改为目标浮起 + 淡色底。
- **字体**：拉丁字母与数字改用 Inter（本地打包）；页面大标题使用得意黑 Smiley Sans；中文正文继续使用系统苹方。
- **修复**：自启面板打开时，鼠标按在卡片上会被误判为「点了面板外」导致面板收起；引导中局域网链接被卡片信息板压住、无法高亮。

## 兼容

- 置顶信息保存在 `settings.json` 的 `pinnedIds`；删除项目、把项目收进组时会自动清理对应置顶。
- 组和组内子项不参与置顶。
- 旧的列表视图设置会被忽略，不会影响卡片视图。

## 验证

- `npm run typecheck`、`npm run build`、ESLint（0 error）。
- `npm test`：诊断引擎黄金文本 + 原有回归全部通过。
- 界面用 Chromium 调试协议实测：1200 窗口下项目区 4 列；详情抽屉 456（2 列）、自启面板 224（1 列）宽度不变；置顶区、菜单栏「置顶」分组、引导各步目标与高亮均实测通过。
