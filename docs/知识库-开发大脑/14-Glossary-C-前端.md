## 第 14 章：专业术语速查表（Glossary）

### C. 前端

> 本类词条：英文按字母序在前，中文按拼音序在后。详解见 [05 开发](05-开发阶段.md) ｜ 返回 [阅读地图](README.md)

| 词 | 人话 |
|---|---|
| CSS | 化妆：颜色字体间距 |
| HMR | 热更新：改代码界面就地变，不用刷新 |
| Hooks | React 里把状态/副作用挂进组件的函数 |
| HTML | 骨架：标题段落按钮的位置 |
| JavaScript | 行为：点按钮发生什么 |
| JSX | React 里 HTML 与 JS 混写的语法 |
| Node.js | 让 JS 能操作电脑的运行环境 |
| npm | 包管理器：装依赖、跑命令 |
| React | 最流行的前端框架（组件拼页面） |
| State Management 状态管理 | 把全局状态集中管起来的库（Redux/Zustand）；核心思想：数据只朝一个方向流（单向数据流），改动可追踪 |
| Tailwind | 用工具类名写样式的流行 CSS 方案 |
| TypeScript | 带类型标签的 JavaScript，写代码时提前拦错 |
| Vite | 新一代构建工具（快） |
| Vue | 前端框架三大家之一 |
| Webpack | 老牌构建工具 |
| CSS 变量 | 定义一次到处引用的"设计令牌"，换主题的基础 |
| 包管理器 | 管"借书还书"（依赖）的工具 |
| 打包 | 把源码加工成成品文件 |
| 防抖/节流 | 高频事件压缩频率的两种套路：防抖=停手才执行（搜索框输入完再查）；节流=固定节奏执行（滚动时每秒最多处理一次） |
| 构建 | 源码加工成成品的工序 |
| 路由 | 管"点哪里跳哪个页面"的导航 |
| 热更新 | 同 HMR |
| 深色模式 | 深色主题 |
| 事件循环 | 单线程 JS 排队干活的机制：慢活丢后台，干完通知回来（详解见[第 5 章 5.0](05-开发阶段.md)） |
| 属性 | 组件之间传的参数 |
| 响应式设计 | 界面自动适配不同屏幕尺寸 |
| 虚拟 DOM | React 先算后改的提速技巧 |
| 压缩 | 成品文件瘦身 |
| 状态 | 组件记着的当下情况 |
| 组件 | 界面的积木块（按钮/卡片/弹窗） |
