## 第 14 章：专业术语速查表（Glossary）

### D. 后端与数据

> 本类词条：英文按字母序在前，中文按拼音序在后。详解见 [04 技术方案](04-技术方案.md)、[10 安全](10-安全专项.md)、[13 数据](13-数据专项.md) ｜ 返回 [阅读地图](README.md)

| 词                | 人话                                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------------- |
| 2FA               | 双因素认证：密码之外再加一道验证                                                                     |
| ACID              | 事务的四大性质：原子性/一致性/隔离性/持久性——"要么全成要么全回滚"的保证                              |
| C                 | 最古老的"元老"语言：操作系统和各类工具的地基，现在主要在底层与嵌入式                                 |
| C#                | 微软系语言：写 Windows 桌面应用（.NET）和 Unity 游戏的主流                                           |
| C++               | C 的升级版：游戏引擎/大型软件主力，性能天花板但难学，新手知道名字即可                                |
| Cookie            | 存在浏览器里的小纸条（记住你是谁）                                                                   |
| CORS 跨域         | 浏览器安全规则：A 网站默认不能调 B 网站接口；B 声明"允许 A"才放行（详解见[第 4 章](04-技术方案.md)） |
| CSRF 跨站请求伪造 | 恶意网站借用你的登录状态偷偷发请求；防御：令牌校验（详解见[第 10 章](10-安全专项.md)）               |
| Dart              | 谷歌出品：写 Flutter 跨平台应用（一套代码跑手机/桌面/网页）的专用语言                                |
| Go                | 编译型后端语言，Google 出品：写法简单、跑得快，天生适合写服务器和工具                                |
| Java              | 老牌企业级后端语言，"一次编写到处运行"，银行/大厂服务器主力，也写 Android                            |
| JWT               | 带签名的通行证：登录后发一串加密字符串，之后请求带着它验签名即可（详解见[第 4 章](04-技术方案.md)）  |
| Kotlin            | Android 官方语言（Java 的现代升级版），写安卓应用首选                                                |
| Lua               | 小巧的嵌入脚本语言，游戏 mod、配置脚本常用                                                           |
| MATLAB            | 数学家和工程师的计算语言：矩阵运算、科研绘图                                                         |
| MySQL             | 最流行的关系型数据库之一                                                                             |
| NoSQL             | 非关系型数据库总称（灵活松散）                                                                       |
| OAuth             | 第三方登录的标准协议（"用微信登录"）                                                                 |
| Objective-C       | iPhone 最早的官方语言，已被 Swift 取代，老 App 代码还在                                              |
| ORM               | 用写代码的方式操作数据库的翻译层                                                                     |
| PHP               | 最早的"做网站专用"语言，WordPress 等大量老网站用它，生态仍庞大                                       |
| PostgreSQL        | 功能强大的开源关系型数据库                                                                           |
| Python            | 解释型"万能胶"语言：代码像念白话一样好懂，写脚本/爬虫/AI/自动化全靠它，新手第一语言                  |
| R                 | 统计学家专用的数据分析语言：做图表、跑统计检验                                                       |
| RBAC              | 按角色发权限的权限管理体系                                                                           |
| Redis             | 内存极速数据库（存缓存用）                                                                           |
| RESTful           | 流行的 API 设计风格                                                                                  |
| Ruby              | 以"让程序员开心"为理念的语言，配 Rails 框架做出过一代明星网站，现在小众                              |
| Rust              | 注重"绝对安全"的现代系统语言：快得像 C，又能在写代码时拦住内存崩溃，Tauri 和很多新 CLI 工具都用它写  |
| SBOM              | 软件物料清单：把项目用的所有依赖列成清单——供应链安全检查的基础                                       |
| Session           | 服务器记着的"本次访问状态"（登录态）                                                                 |
| SQL               | 和数据库对话的查询语言，写法像英文句子：`SELECT 名字 FROM 用户表 WHERE 年龄>30`                      |
| SQLite            | 装进程序里的微型数据库（单文件）                                                                     |
| Swift             | 苹果官方原生语言：只给 iPhone/Mac 写程序时用它，体验最好但出不了苹果家门                             |
| Token             | 登录后发的通行证                                                                                     |
| WebSocket         | 实时通信长连接（服务器主动推消息）                                                                   |
| 备份              | 数据复制一份存别处保命                                                                               |
| 表                | 数据库里的一张表格                                                                                   |
| 关系型数据库      | 表与表有严格关联的数据库                                                                             |
| 哈希              | 单向指纹计算（存密码用）                                                                             |
| 缓存              | 常用东西提前放抽屉                                                                                   |
| 记录              | 表格的一行                                                                                           |
| 加密              | 内容搅乱，只有拿钥匙的能看懂                                                                         |
| 接口              | API 的口语说法                                                                                       |
| 幂等              | 同一请求发两次结果一样——支付接口必须幂等（双击付款不能扣两次钱）                                     |
| 密钥              | 密码/凭证的总称                                                                                      |
| 迁移              | 数据从旧结构搬到新结构                                                                               |
| 死锁              | 两件事互相等对方放资源，全卡死——数据库会自动检测并解开一个                                           |
| 事务              | 一组操作要么全成功要么全回滚                                                                         |
| 索引              | 表格的目录，查询加速                                                                                 |
| 消息队列          | 任务排队的中转站（RabbitMQ/Kafka）                                                                   |
| 序列化            | 数据对象↔JSON 文本的互转                                                                             |
| 业务逻辑          | 产品规则的代码化                                                                                     |
| 中间件            | 请求进来先过的安检层                                                                                 |
| 主键              | 每行数据的身份证号                                                                                   |
| 状态码            | 结果的数字代号（200 成功/404 找不到/500 挂了）                                                       |
| 字段              | 表格的一列                                                                                           |
