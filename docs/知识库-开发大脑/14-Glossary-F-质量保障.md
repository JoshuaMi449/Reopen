## 第 14 章：专业术语速查表（Glossary）

### F. 质量保障

> 本类词条：英文按字母序在前，中文按拼音序在后。详解见 [06 测试](06-测试阶段.md) ｜ 返回 [阅读地图](README.md)

| 词 | 人话 |
|---|---|
| E2E 测试 | 模拟真人走全流程的测试 |
| ESLint | JS 代码规范检查器 |
| Lint | 查代码规范的统称 |
| Mock | 假数据/假后端，顶替真家伙做测试 |
| Prettier | 代码格式化器 |
| Retry 重试 | 失败后自动再试的策略——要配退避（间隔递增）和幂等（重复执行无害） |
| Spy 间谍 | 测试替身：真的执行，但偷偷记录行为 |
| Stub 桩 | 测试替身：只返回预先写好的答案 |
| TDD | 测试驱动开发：先写测试→再写代码让测试通过→再清理（红绿重构循环） |
| UAT | 让真实用户亲手验收 |
| 测试用例 | "输入什么→期望什么"的检查项 |
| 单元测试 | 单个零件单独测 |
| 断言 | 测试里的判定句 |
| 覆盖率 | 代码被测试跑过的比例 |
| 回归测试 | 改完把老测试全重跑一遍 |
| 集成测试 | 零件拼起来测 |
| 技术债 | 赶工留下的糙代码，以后要还 |
| 冒烟测试 | 上线前快速点核心流程 |
| 内存泄漏 | 内存只涨不降，跑几天就卡——常驻应用的高发病 |
| 渗透测试 | 像黑客一样攻击自己系统找漏洞 |
| 手动测试 | 人肉点 |
| 压测 | 模拟大量用户同时用，看扛不扛得住 |
| 自动化测试 | 脚本自动跑 |
