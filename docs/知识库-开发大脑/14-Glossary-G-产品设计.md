## 第 14 章：专业术语速查表（Glossary）

### G. 产品设计

> 本类词条：英文按字母序在前，中文按拼音序在后。详解见 [03 设计](03-设计阶段.md)、[09 运营](09-运营与迭代.md)、[12 兼容](12-兼容与国际化.md) ｜ 返回 [阅读地图](README.md)

| 词                            | 人话                                                                      |
| ----------------------------- | ------------------------------------------------------------------------- |
| Accelerator 应用内快捷键      | 应用内部的快捷键（⌘S 保存），区别于全局快捷键                             |
| Always on Top 窗口置顶        | 窗口钉在所有窗口最上层                                                    |
| App Icon 应用图标             | 桌面应用门面图标，含尺寸规格与 Squircle 裁剪规则                          |
| Auto Save 自动保存            | 改动自动落盘，无需手动保存                                                |
| Badge                         | 小圆点/小数字标（状态点、未读数）                                         |
| Button                        | 按钮                                                                      |
| Card                          | 卡片                                                                      |
| Checkbox                      | 复选框（方框，可多选）                                                    |
| Command Palette 命令面板      | 按一组键呼出的命令搜索框                                                  |
| Component States 组件四态     | 悬停/按下/聚焦/禁用，每个控件都要设计                                     |
| Context Menu 右键菜单         | 右键弹出的操作菜单                                                        |
| Conversion Rate 转化率        | 走过某一步的用户比例                                                      |
| DatePicker                    | 日期选择器                                                                |
| DAU/MAU                       | 日活/月活用户数，衡量人气的基础指标                                       |
| Dialog                        | 要你确认的对话框                                                          |
| Drag & Drop 拖放              | 按住拖到目标处放下的交互                                                  |
| Drawer                        | 从边缘滑出的面板                                                          |
| Dropdown                      | 下拉菜单                                                                  |
| Empty State                   | 空状态提示                                                                |
| Figma                         | 行业标准设计软件                                                          |
| File Picker 文件选择对话框    | 系统自带的"打开/保存文件"原生对话框                                       |
| Filter/Sort 筛选/排序         | 列表数据的筛选项与排序规则                                                |
| Flat Design 扁平设计          | 去掉阴影立体感、纯色块的现代风格                                          |
| Frameless Window 无边框窗口   | 没有系统标题栏的自定义窗口                                                |
| Funnel 漏斗                   | 每一步流失多少用户的分析模型——找最陡的落差，就是最该修的地方              |
| Glassmorphism 玻璃拟态        | 半透明磨砂+高光的"毛玻璃"风格                                             |
| Gradient 渐变                 | 颜色平滑过渡的效果                                                        |
| Guided Tour                   | 分步引导（主界面蒙层+弹出窗口一步步教学，配上一步/下一步/跳过 Skip 按钮） |
| Hi-Fi                         | 高保真稿（上色带图标）                                                    |
| Hide to Tray 隐藏到托盘       | 点关闭缩到托盘常驻而非退出                                                |
| HIG                           | 苹果官方人机界面指南（覆盖 iOS/macOS/watchOS 等全平台）                   |
| Home                          | 首页                                                                      |
| HSL                           | 色相/饱和度/明度描述颜色的方式，调色比 Hex 直觉                           |
| IA                            | 信息架构：内容怎么组织                                                    |
| Infinite Scroll 无限滚动      | 滚到底自动加载下一页                                                      |
| Input                         | 单行输入框                                                                |
| Landing                       | 落地页（营销页）                                                          |
| Lo-Fi                         | 低保真稿（线框图加细节）                                                  |
| Loading                       | 加载中转圈                                                                |
| Material Design               | 谷歌官方设计规范                                                          |
| Menu Bar 应用菜单栏           | macOS 屏幕顶部的"文件/编辑/视图"菜单条                                    |
| Modal                         | 模态弹窗（挡住后面必须处理）                                              |
| Navbar                        | 顶部导航栏                                                                |
| North Star Metric 北极星指标  | 全产品只盯一个核心指标                                                    |
| NPS                           | 净推荐值："你会推荐给朋友吗"0-10 分，9-10 分推荐者减 6 分以下贬损者       |
| OKR                           | 目标与关键结果：团队定目标的方法（O 是方向，KR 是可量化的结果）           |
| Onboarding                    | 首次使用引导（含欢迎页、分步引导 Guided Tour 等形式）                     |
| Overlay 蒙层                  | 压暗背景的半透明层，Modal/分步引导都靠它                                  |
| Palette 色板                  | 一组搭配好的颜色集合（主色/辅助色/语义色）                                |
| Persona 用户画像              | 把目标用户写成有名字有故事的虚拟人                                        |
| Placeholder 占位符            | 输入框里灰色的提示文字（"请输入名称"）                                    |
| Progress Bar                  | 进度条                                                                    |
| Radio                         | 单选按钮（圆圈，单选）                                                    |
| Rich Text Editor 富文本编辑器 | 能加粗插图的文字编辑控件                                                  |
| Settings                      | 设置页                                                                    |
| Scrollbar 滚动条              | 内容超长时的滚动指示条                                                    |
| Search Bar 搜索框             | 独立搜索输入条，带聚焦/清空/快捷键唤起                                    |
| SF Symbols                    | 苹果官方界面图标符号库（工具栏/菜单栏/按钮等 UI 图标用）                  |
| Shadow 阴影                   | 卡片/弹窗的层级暗示                                                       |
| Skeleton                      | 骨架屏（加载占位）                                                        |
| Skeuomorphism 拟物化          | 把 UI 做得像真实物体，与扁平设计对立                                      |
| Slider                        | 滑块                                                                      |
| Snackbar                      | 底部条状提示                                                              |
| Splash                        | 启动页                                                                    |
| Splitter 分隔条               | 左右面板间可拖动调宽的分隔条                                              |
| Squircle                      | macOS 图标那种"圆角矩形"专用形状                                          |
| Status Bar 状态栏             | 窗口底部常驻状态信息行                                                    |
| Status Indicator 状态指示点   | 🟢⚪ 这种小圆点，一眼看出运行/停止状态                                    |
| Switch                        | 开关（绿滑块）                                                            |
| Tab                           | 选项卡                                                                    |
| Tag                           | 分类标签                                                                  |
| Textarea                      | 多行输入框                                                                |
| Title Bar 标题栏              | 窗口顶部带标题和红绿灯按钮的那条                                          |
| Toast                         | 角落轻提示（自动消失）                                                    |
| Toolbar 工具栏                | 窗口顶部一排工具按钮区                                                    |
| Tooltip                       | 悬停气泡说明                                                              |
| Tree 树形控件                 | 层级展开的目录结构                                                        |
| Typography 字体排印           | 字号/字重/行高的整套字体规则                                              |
| UI                            | 用户界面（界面长什么样、好不好看，和 UX 的分工：UI 管好看，UX 管好用）    |
| Undo/Redo 撤销/重做           | 操作后悔药（⌘Z / ⌘⇧Z）                                                    |
| Upload 上传控件               | 选择/拖入文件交给应用的控件                                               |
| UX                            | 用户体验（好不好用）                                                      |
| Welcome 欢迎页                | 首次打开时迎接用户的第一屏（介绍+开始按钮）                               |
| Wireframe                     | 线框图（黑白草稿）                                                        |
| Wizard 向导                   | "第 1 步→第 2 步"的分步流程页                                             |
| 标注                          | 设计稿上的精确尺寸颜色标注（开发施工图）                                  |
| 动效                          | 元素的动态效果（按下反馈、切换过渡）                                      |
| 对比度                        | 文字与背景的明暗差，可访问性的硬指标                                      |
| 交互设计                      | 设计"怎么用"                                                              |
| 可访问性                      | 残障用户也能用                                                            |
| 可用性                        | 用得顺不顺                                                                |
| 埋点                          | 在代码里埋计数点，统计用户行为                                            |
| 切图                          | 把设计稿元素导出成开发能用的文件                                          |
| 栅格系统                      | 页面按固定列数排布的对齐网格                                              |
| 设计规范                      | 颜色字号间距的规定                                                        |
| 设计系统                      | 组件库+设计规范的总称                                                     |
| 视觉层级                      | 通过大小/颜色/位置引导用户先看哪后看哪                                    |
| 视觉设计                      | 设计"长多好看"                                                            |
| 信息架构                      | 内容怎么组织                                                              |
| 用户流程                      | 用户完成一件事的路径                                                      |
| 圆角                          | 控件的圆角弧度规范                                                        |
| 原型                          | 可点击的假应用                                                            |
| 主题/换肤                     | 一套界面多套配色皮肤的机制                                                |
| 组件库                        | 标准件集合                                                                |
