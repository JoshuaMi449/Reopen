# 产品开发知识库（开发大脑）

> **本文档的定位**：正规互联网公司从想法到上线的完整知识库。它是一份**通用文档**——只讲"产品开发这件事本身是怎么做的、有哪些环节、每个专业名词是什么意思"，**不包含任何具体产品的决策**（具体产品的内容写在各项目自己的需求文档里）。
>
> **读者**：不懂技术的产品负责人 / 独立开发者 / 任何想弄明白"开发一个产品到底要做什么"的人。
>
> **作者视角**：资深程序员，把每个环节讲透，所有专业名词都带人话解释。
>
> **使用场景**：开发任何产品（网页、桌面应用、手机 app、小程序）时，这份文档都是随时可查的"大脑"。

## 三条学习路线

1. **我要开发一个产品（最快上手）**：00 → 01 → 02 → 05 → 17 → 08，遇不懂的词查 14-Glossary
2. **我要理解完整流程（正规军）**：00 → 01 到 10 顺序通读 → 11/12/13 按需 → 17 → Glossary 当字典
3. **我要快速查词（工具用法）**：直接进 14-Glossary-A 到 H，或全文搜索

## 维护说明

- 本知识网络由单文件版（`docs/01-产品开发知识库-开发大脑-备份单文件.md`）脚本切割而成，切割经逐行校验零丢失
- 修改知识：直接改对应主题文件；改动 Glossary 词条时同步检查对应正文章节是否也要改
- 新增知识：新增文件并在本 README 目录表加一行；概念之间有联系的用 Markdown 链接互相串（如 `[相关概念](14-Glossary-G-产品设计.md)`）
