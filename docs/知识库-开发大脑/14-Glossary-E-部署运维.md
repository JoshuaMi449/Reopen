## 第 14 章：专业术语速查表（Glossary）

### E. 部署运维

> 本类词条：英文按字母序在前，中文按拼音序在后。详解见 [07 运维](07-运维阶段.md) ｜ 返回 [阅读地图](README.md)

| 词               | 人话                                                 |
| ---------------- | ---------------------------------------------------- |
| CDN              | 内容分发网络：静态资源全球缓存、就近取               |
| Cron             | 按计划自动干活的任务（定时备份、定期清理）           |
| DNS              | 域名→IP 的全球电话簿                                 |
| Docker           | 程序+环境打包成集装箱                                |
| HTTP             | 网页传输协议                                         |
| HTTPS            | 加密的网页传输协议（锁图标）                         |
| IP 地址          | 服务器的门牌号                                       |
| K8s              | 管理海量集装箱的调度系统                             |
| Nginx            | 最流行的服务器软件（前台接待）                       |
| Sentry           | 崩溃收集平台                                         |
| SLA              | 可用性承诺（99.9% 时间在线）                         |
| SSH              | 远程登录服务器/连 GitHub 的标准加密通道              |
| SSL 证书         | HTTPS 加密用的数字锁                                 |
| Timeout 超时     | 等待超过时限就判定失败，防止无限卡住                 |
| VPS              | 便宜的虚拟独立服务器                                 |
| Webhook          | 别人系统一有动静就主动调你的接口                     |
| Whitelist 白名单 | 只放行名单里的对象（扫描时排除/包含指定目录）        |
| 崩溃收集         | 闪退时自动上报案发现场                               |
| 部署             | 把代码运到服务器跑起来                               |
| 反向代理         | 前台把请求转给后台服务，对外只露一个门               |
| 告警             | 出问题自动通知人                                     |
| 负载均衡         | 把请求分给多台服务器的交警                           |
| 监控             | 实时盯服务健康                                       |
| 金丝雀发布       | 新版本只给少数"哨兵"用户先尝，出问题只影响小部分人   |
| 进程守护         | pm2/systemd：服务挂了自动拉起                        |
| 扩容             | 不够用加服务器                                       |
| 蓝绿部署         | 两套环境（蓝在服务、绿待命），新版验证 OK 一键切流量 |
| 日志             | 程序的行车记录仪                                     |
| 日志分级         | DEBUG/INFO/WARN/ERROR 四档                           |
| 容器             | Docker 打包出的集装箱                                |
| 域名             | 服务器的好记名字                                     |
| 云服务商         | 出租云端电脑的公司                                   |
| 灾备             | 灾难预案：异地备份 + 恢复演练                        |
