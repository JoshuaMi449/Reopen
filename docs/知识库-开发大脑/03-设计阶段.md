## 第 3 章：设计阶段（设计师的世界）

### 3.1 是什么

设计阶段回答一个问题：**"这个东西长什么样、怎么用？"**

设计分两层，外行常混为一谈：

- **交互设计（UX）**：好不好用——按钮放哪、点一下发生什么、流程顺不顺。这是"逻辑活"
- **视觉设计（UI）**：好不好看——颜色、字体、间距、图标。这是"美学活"

正规流程：先交互后视觉，先定"怎么用"再定"长多好看"。

### 3.2 标准做法：四级进化

设计稿不是一步到位的，正规团队画四轮：

| 级别    | 名词             | 人话                             | 像什么             |
| ------- | ---------------- | -------------------------------- | ------------------ |
| 第 1 级 | 线框图 Wireframe | 黑白草图，只画"哪块放什么"       | 毛坯房户型图       |
| 第 2 级 | 低保真 Lo-Fi     | 线框图加细节：每个按钮文字都写上 | 简装修效果图       |
| 第 3 级 | 高保真 Hi-Fi     | 上色、上图标、上真实内容         | 精装修效果图       |
| 第 4 级 | 原型 Prototype   | 可点击的"假应用"，能模拟操作流程 | 样板间，能走进去逛 |

个人项目的务实做法：**线框图必须画（哪怕是纸上的），高保真可以简化**。AI 时代，AI 可以根据描述直接出高保真稿，但线框图阶段"理清布局"这一步不能省。

### 3.3 设计工具

| 工具          | 人话                                             |
| ------------- | ------------------------------------------------ |
| Figma         | 目前行业标准的设计软件（在浏览器里用），多人协作 |
| Sketch        | 老牌 Mac 设计软件                                |
| 即时设计/摹客 | 国内同类工具                                     |
| 纸和笔        | 永远不过时的第一轮工具                           |

### 3.4 标准做法：设计系统（Design System）

**设计系统** = 把界面上反复出现的元素（颜色、字体、按钮、卡片）做成一套"标准件"，全产品统一使用。

- 好处：界面风格统一、改一处全改、开发不用重复造轮子
- 关键名词：**组件库（Component Library）**——按钮/输入框等标准件的集合；**设计规范（Design Spec）**——颜色值、字号、间距的规定
- 人话：就像装修公司给全小区统一的瓷砖型号和门把手款式，每家都在标准里选

### 3.5 UX 概念

| 名词       | 全称                           | 人话                                                                             |
| ---------- | ------------------------------ | -------------------------------------------------------------------------------- |
| 信息架构   | IA（Information Architecture） | 内容怎么组织：哪个页面套哪个页面、菜单怎么分                                     |
| 用户流程   | User Flow                      | 用户完成一件事要经过的路径："打开→登录→点新建→填表→保存"                         |
| 可用性     | Usability                      | 用户能不能顺利用完不卡壳                                                         |
| 可访问性   | a11y（Accessibility）          | 残障人士（如视障）也能用，屏幕朗读器等                                           |
| 响应式设计 | Responsive Design              | 同一界面在不同尺寸屏幕上自动适配                                                 |
| 深色模式   | Dark Mode                      | 深色主题，省电护眼                                                               |
| 拖放       | Drag & Drop                    | 鼠标按住拖到目标处放下（拖文件进窗口、拖卡片排序），桌面应用最常用的交互之一     |
| 筛选/排序  | Filter / Sort                  | 列表数据的筛选项和排序规则（按名称/时间/手动拖拽等），访达的排序方式切换就是这个 |
| 撤销/重做  | Undo / Redo                    | 操作后悔药（⌘Z / ⌘⇧Z），编辑类应用的基本能力                                     |
| 命令面板   | Command Palette                | 按一组键（如 ⌘K）呼出的命令搜索框，打字找功能（被 VS Code 带火的模式）           |
| 自动保存   | Auto Save                      | 改动自动落盘，无需手动保存，现代工具类应用标配                                   |
| 窗口置顶   | Always on Top                  | 窗口"钉"在所有窗口最上层，小工具常驻模式                                         |
| 隐藏到托盘 | Hide to Tray                   | 点关闭按钮不是退出而是缩到托盘图标常驻，随时唤回                                 |
| 无边框窗口 | Frameless Window               | 没有系统标题栏的自定义窗口，界面自己画标题区，很多现代工具用                     |
| 无限滚动   | Infinite Scroll                | 滚到底自动加载下一页（和 Pagination 分页是两种方案）                             |
| 向导       | Wizard                         | 安装器/设置里"第 1 步→第 2 步→第 3 步"的分步流程页                               |

### 3.6 UI 组件名词大全（设计师和开发的共同语言）

界面上的一切"零件"都有标准叫法。需求文档里写"点击右上角的按钮弹出确认弹窗"，团队里每个人都明白做的是什么：

| 名词                       | 人话                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------ |
| Button 按钮                | 点了发生一件事                                                                       |
| Input 输入框               | 单行打字的地方                                                                       |
| Textarea 文本域            | 多行打字的地方                                                                       |
| Dropdown 下拉菜单          | 点一下弹出一列选项                                                                   |
| Select 选择器              | 从一堆选项里选一个                                                                   |
| Switch / Toggle 开关       | 拨一下就开/关（系统设置里那种绿滑块）                                                |
| Tab 选项卡                 | 顶部几个标签切来切去                                                                 |
| Radio 单选按钮             | 一组选项只能选一个（圆圈）                                                           |
| Checkbox 复选框            | 一组选项可选多个（方框）                                                             |
| Modal 模态弹窗             | 弹出来挡住后面，必须处理它才能继续                                                   |
| Dialog 对话框              | 要你确认/回答的弹窗（"确定删除吗？"）                                                |
| Drawer 抽屉                | 从屏幕边缘滑出来的面板                                                               |
| Toast 轻提示               | 角落弹一下自动消失（"保存成功"）                                                     |
| Snackbar 提示条            | 底部条状提示，带操作按钮                                                             |
| Tooltip 气泡提示           | 鼠标悬停时冒出的小字说明                                                             |
| Popover 浮层               | 点某个元素后在其旁边弹出的面板                                                       |
| Badge 徽标                 | 小圆点/小数字标（未读消息数、在线状态点）                                            |
| Card 卡片                  | 圆角方块，一个信息单元                                                               |
| List 列表                  | 一条一条的条目                                                                       |
| Table 表格                 | 行和列                                                                               |
| Breadcrumb 面包屑          | "首页 / 设置 / 账号"这种路径导航                                                     |
| Pagination 分页            | 一页装不下时的"第 1 2 3 页"                                                          |
| Empty State 空状态         | 列表为空时的提示（"还没有数据，点这里创建"）                                         |
| Skeleton 骨架屏            | 加载中的灰色占位条（先占位后填内容）                                                 |
| Loading 加载中             | 转圈圈                                                                               |
| Progress Bar 进度条        | 完成到百分之多少                                                                     |
| Navbar 导航栏              | 顶部的栏目条                                                                         |
| Sidebar 侧边栏             | 左侧的菜单栏                                                                         |
| Footer 页脚                | 底部的信息区                                                                         |
| Accordion 手风琴           | 点击展开/收起的折叠块                                                                |
| Stepper 步骤条             | "第 1 步→第 2 步→第 3 步"的进度指示                                                  |
| DatePicker 日期选择器      | 选日期的日历控件                                                                     |
| Slider 滑块                | 拖动的进度条（音量调节）                                                             |
| Avatar 头像                | 用户头像图                                                                           |
| Tag 标签                   | 分类小标签                                                                           |
| Divider 分割线             | 分隔内容的线                                                                         |
| Icon 图标                  | 小图形符号                                                                           |
| Context Menu 右键菜单      | 鼠标右键（或双指轻点）弹出的操作菜单（启动/编辑/删除）                               |
| Toolbar 工具栏             | 窗口顶部一排工具按钮区（和 Navbar 导航不同：工具按钮不是栏目）                       |
| Menu Bar 应用菜单栏        | macOS 屏幕最顶部的"文件/编辑/视图"菜单条，桌面应用和网页的核心区别之一               |
| Status Bar 状态栏          | 窗口底部常驻一行小字显示状态（版本、数量、连接状态）                                 |
| Title Bar 标题栏           | 窗口最顶部带标题和红绿灯（最小化/关闭）按钮的那条                                    |
| Tree 树形控件              | 层级展开的目录结构（文件树），文件夹管理类界面的标配                                 |
| Search Bar 搜索框          | 独立搜索输入条，带聚焦、清空、快捷键唤起                                             |
| File Picker 文件选择对话框 | 系统自带的"打开文件/保存文件"原生对话框                                              |
| Splitter 分隔条            | 左右面板之间可拖动调整宽度的分隔条                                                   |
| Scrollbar 滚动条           | 内容超长时的滚动指示条                                                               |
| Upload 上传控件            | 选择/拖入文件交给应用的控件                                                          |
| Overlay 蒙层               | 盖在界面上压暗背景的半透明层，Modal/弹窗/分步引导都靠它隔断底层操作                  |
| 组件四态                   | Hover 悬停 / Pressed 按下 / Focused 聚焦 / Disabled 禁用——每个控件都要设计这四种状态 |

### 3.7 页面类型名词

| 名词                 | 人话                                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------------------ |
| Home 首页            | 打开应用第一眼看到的主界面                                                                                   |
| List Page 列表页     | 一列条目                                                                                                     |
| Detail Page 详情页   | 点进某一条后的完整信息页                                                                                     |
| Form Page 表单页     | 填一堆信息的页面                                                                                             |
| Settings Page 设置页 | 调各种选项的地方                                                                                             |
| About Page 关于页    | 版本号、作者、协议信息                                                                                       |
| Login Page 登录页    | 登录入口                                                                                                     |
| Landing Page 落地页  | 独立宣传页（网站营销用）                                                                                     |
| Onboarding 引导页    | 第一次使用时的引导教程（广义，包含欢迎页/功能预览等）                                                        |
| Guided Tour 分步引导 | 主界面变暗（蒙层）+ 弹出讲解窗口，一步步指向界面元素教学，配上一步/下一步/跳过。是 Onboarding 的一种具体形式 |
| Splash 启动页        | 打开瞬间的过渡画面                                                                                           |
| 404 Page             | 页面不存在的提示页                                                                                           |

### 3.8 常见误区

- ❌ **跳过线框图直接写代码**——布局问题在草图上改 1 分钟，在代码里改 1 小时。
- ❌ **设计追求"独特"忽略"熟悉"**——用户习惯了开关长什么样，就做成那样；独特留给亮点功能。
- ❌ **组件叫法不统一**——需求里说"弹窗"、设计说"Modal"、开发说"Dialog"，对不上号就返工。这就是为什么上面两张表要存在。
- ❌ **一个人拍脑袋定设计**——至少让一个"没用过的人"试一下，立刻暴露流程问题。

### 3.9 设计交付与动效

设计做完后要"交接"给开发，交接物有标准叫法：

| 名词                       | 人话                                                         |
| -------------------------- | ------------------------------------------------------------ |
| 切图 Export Assets         | 把设计稿里的图标、图片导出成开发能直接用的文件               |
| 标注 Specification（Spec） | 在稿子上标清每个元素的精确尺寸、颜色值、字号——开发的"施工图" |
| 交互动效 Motion/Animation  | 元素的动态效果：按钮按下的反馈、页面切换的过渡、弹窗弹出方式 |
| 动效曲线 Easing            | 动效的快慢节奏（先快后慢更像物理世界）                       |

**个人项目务实做法**：Figma 自带标注和切图功能，开发按标注写即可；动效第一版从简，别让"炫"拖垮进度。
