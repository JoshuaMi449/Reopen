## 第 14 章：专业术语速查表（Glossary）

### H. 桌面应用专属

> 本类词条：英文按字母序在前，中文按拼音序在后。详解见 [05 开发](05-开发阶段.md) ｜ 返回 [阅读地图](README.md)

| 词                          | 人话                                                           |
| --------------------------- | -------------------------------------------------------------- |
| App Sandbox 沙盒            | macOS 把应用限制在专属区域运行的机制                           |
| BrowserWindow               | Electron 的窗口对象                                            |
| Chromium                    | 打包进应用的浏览器内核                                         |
| Custom URL Scheme           | 注册 myapp:// 链接，从浏览器唤起本应用                         |
| dmg                         | macOS 安装包格式                                               |
| Dock 程序坞                 | macOS 底部图标栏，右键弹快捷菜单                               |
| Electron                    | 用网页技术做桌面应用的框架                                     |
| electron-builder            | Electron 打包工具（出 dmg/exe）                                |
| exe                         | Windows 安装包格式                                             |
| File Association 文件关联   | 双击某后缀文件自动用你的应用打开                               |
| Gatekeeper                  | macOS 的门卫（拦未签名应用）                                   |
| IPC                         | 进程间通信（对讲机）                                           |
| Keychain 钥匙串             | macOS 系统密码保险库                                           |
| launchd                     | macOS 的开机自启系统                                           |
| Menu Bar App 菜单栏应用     | 只在顶部菜单栏显示图标的常驻小工具                             |
| Preload                     | 渲染进程与主进程之间的安全门岗                                 |
| Single Instance Lock 单例锁 | 防开两个实例打架，第二个自动唤起第一个                         |
| Singleton 单例模式          | 全局只允许一个实例的设计，应用级就是单例锁                     |
| SmartScreen                 | Windows 的同类门卫                                             |
| Tauri                       | 网页界面+轻壳的桌面框架                                        |
| TCC 权限体系                | macOS 隐私权限管理（摄像头/文件夹访问弹窗）                    |
| 登录项                      | macOS"系统设置→通用→登录项"面板，开机自启在这里管理            |
| 端口冲突                    | 两程序抢同一端口导致启动失败                                   |
| 公证                        | 苹果官方检查后放行                                             |
| 健康检查                    | 定期自检"还活着吗、端口还通吗"                                 |
| 开发者证书                  | 签名要用的"章"（99 美元/年）                                   |
| 开机自启                    | 登录系统自动启动                                               |
| 离线模式                    | 没网也能完整使用的模式                                         |
| 配置文件                    | 用户设置存储位置（macOS 规范：~/Library/Application Support/） |
| 签名                        | 给应用盖生产厂商章                                             |
| 守护进程                    | 后台常驻、无界面的服务进程                                     |
| 托盘                        | 菜单栏小图标常驻                                               |
| 渲染进程                    | 画界面的进程                                                   |
| 主进程                      | 和系统打交道的总管进程                                         |
| 自动更新                    | 应用自己检测并升级                                             |
