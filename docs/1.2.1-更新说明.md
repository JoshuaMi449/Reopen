# Reopen 1.2.1 更新内容

相对 v1.2.0，本版修两个「显示不对」的问题。

## 修复

- **环境监测不会自动刷新**：此前只在打开设置页那一刻检测一次。如果设置页开着的时候去装了 Docker / Node，切回来看到的仍是「未安装」。现在窗口每次重新获得焦点都会重新检测——装完东西切回应用即可看到最新状态。
- **版本号显示错误**：关于页、菜单「关于」、托盘面板三处的版本号此前是手写字符串，发版时容易漏改（v1.2.0 就漏了，界面仍显示 1.1.0）。现改为构建时从 `package.json` 自动注入，不再需要手工维护。

## 验证

- `npm test`：诊断引擎黄金文本 + 原有 8 项回归。
- `npm run typecheck`、`npm run lint`：静态检查。
- 用真实 Electron 二进制在模拟 GUI 的最小 PATH 下实测环境检测，四个运行时均能正确识别。

仅提供 Apple Silicon macOS 安装包；使用本地签名，未进行 Apple Developer 公证。
